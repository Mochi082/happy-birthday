# 誕生日サイト

スマホ向けの静的サイト。GitHub Pages でそのまま公開できます。

## ファイル構成

```
index.html      ページの骨組み（基本さわらない）
css/style.css   見た目
js/data.js      ★ 内容（名前・誕生日・プロフィール・写真・メッセージ）
js/main.js      動き（基本さわらない）
images/         写真を置く場所
```

## 内容を変える

`js/data.js` だけ編集すればOK。

- 写真を追加：`images/` に画像を入れて、`photos` に `{ src: "images/07.jpg", title: "20歳", text: "成人式" },` を1行足す
- 並び順は `photos` に書いた順
- メッセージが要らなければ `messages: []`
- 画像が見つからないときはピンクのダミー表示になるので、ファイル名の間違いはすぐ分かります

### 効果音

ろうそくを消す音とお祝いの音は、ブラウザ上で合成しています（音声ファイルは不要）。
好きな音源に差し替えたいときは、`audio/` にファイルを置いて `sounds: { blow: "audio/blow.mp3", pop: "audio/pop.mp3" }` のように指定してください。
ファイルが見つからないときは合成音が鳴ります。
フリー素材を使うときは、そのサイトの利用規約（クレジット表記が必要か、など）を確認してください。

### 写真のコツ

- スマホで見るので **長辺1200px程度・1枚300KB前後** に縮小しておくと表示が速い
- スライドは縦長 4:5 で表示（はみ出た部分は切れる）。タップすると全体が見られる
- ファイル名は英数字のみにする（日本語やスペースは避ける。大文字小文字も区別されるので `.JPG` と `.jpg` に注意）

## 手元で確認

`index.html` をブラウザで開くだけ。スマホ表示は、PCのChromeで F12 を押してからスマホアイコン（Ctrl+Shift+M）で確認できます。

## GitHub Pages で公開

1. GitHub で新しいリポジトリを作る（無料プランでは Public にする必要あり）
2. このフォルダの中身をアップロード（Webの「Add file → Upload files」にドラッグ＆ドロップでもOK）
3. リポジトリの **Settings → Pages** で「Branch: main / (root)」を選んで Save
4. 1〜2分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で見られる

更新したいときは、変えたファイルを同じようにアップロードし直すだけです（反映まで1〜2分）。

> 注意：Public リポジトリなので、URL を知っていれば誰でも見られ、写真もリポジトリから見えます。検索エンジンには出ないように設定してありますが、見られて困る写真は載せないでください。
